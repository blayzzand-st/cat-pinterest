## Description

Тестовое задание в компанию `VK` (команда Учи.ру) на позицию Intern Frontend-разработчик.  
Приложение представляет собой мини-SPA из двух страниц для просмотра изображений котиков, полученных с `thecatapi.com`.

**Используемый стек:**

- React 19
- TypeScript
- Tailwind CSS
- React Router

### Features

- Бесконечная прокрутка через IntersectionObserver
- Добавление котиков в избранное с сохранением в localStorage
- Логика загрузки инкапсулирована в кастомный хук `useCats`
- Skeleton-загрузка карточек
